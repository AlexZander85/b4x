# ABD-6 — QUIC ladder

The detector models Q0–Q7 as separate UDP/443, Initial, Version Negotiation, Retry, handshake, HTTP/3 headers, body-progress, and control stages. Observations retain IP family and fingerprint dimensions and can carry a TCP comparison without merging causal evidence.

A failed target does not imply a global UDP block when a scoped UDP/443 control is healthy. QUIC controls and observer outcomes remain evidence only; they cannot authorize a packet or routing action.
